Frequently Asked Questions

How does Smart Match work?

It uses your trip purpose, budget, seat requirement and transmission preference to filter suitable cars.

Can I compare multiple cars?

Yes. Select up to three cars and open the Compare Cars section to see them side-by-side.

Does this frontend have a real database?

Not yet. This version uses demo data and localStorage. MySQL and Node.js/Express can be connected next.

Can customers cancel bookings?

The UI is prepared for booking management. Real cancellation rules will be implemented with the backend.
